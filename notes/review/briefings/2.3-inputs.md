# Briefing 2.3: Getting data in (record)

Interactive page: `2.3-inputs.html`. One representation (row-normalised bin-averaged
L, log-scales, weights, selection) reached by every constructor.

- Raw matrix: validation; mass → density (÷ volume); log input exponentiated
  after subtracting the row max; sparse kept (copied); empty rows raise or are
  dropped (`drop_empty`), per-object meta follows.
- from_gaussian: exact CDF differences ÷ width, in log space with the
  mirrored-tail trick; N-D = per-axis outer sum (diagonal covariance); stores
  mean/σ for exact `sample_values`. Correlated per-object covariance (#2):
  options exact bivariate CDFs (2-D) / QMC, adaptive sub-cell quadrature,
  principal-axis rotation.
- from_posteriors: L ∝ P/Π (flat within bins); interim prior "flat" / array
  (read in the posteriors' representation unless overridden) / callable
  (sub-bin quadrature); representation warning. Explorer (N=3000, 12 log bins,
  σ=0.08(1+z)): TV to truth correct 0.065, posteriors-as-likelihoods 0.198
  (peaked interim), interim density as mass 0.077, posterior density as mass
  0.109. Check: `experiments/2.3_inputs_check.js`.
- from_samples: weighted histogram ÷ Π; n_eff and outside fraction in meta;
  sparse when < 30% non-zero; warns when median n_eff < 20. Empty bins get
  L = 0 (objects declared impossible there) → smoothing options to decide.
- from_function / from_distributions: Gauss–Legendre n_sub per bin per axis
  (3 / 5 defaults); exact CDFs for 1-D distributions. Worst relative error for
  a Gaussian: 3 points 4.8% at σ = h/4, 72% at h/10; 5 points 0.037% at h/4,
  16% at h/10. Adaptive refinement proposed.
- from_response: one row per reco bin weighted by counts; efficiency as
  on_measurement selection; migration-matrix convention with explicit
  efficiency; column-sum checks.
- from_classifier: p / π_train on categorical bins (prior shift; EMQ is its EM
  point estimate); relies on calibration.
- Utilities: compress (exact, log-scale bookkeeping), subset, to_sparse,
  stack (one EM step; #11).
- To discuss: smoothing for samples; general bin shapes in every constructor;
  correlated Gaussians implementation; adaptive quadrature; one constructor
  surface (I-18); classifier calibration.
