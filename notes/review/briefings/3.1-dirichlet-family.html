The Dirichlet family

Dirichlet, generalised Dirichlet, Dirichlet trees and Pólya trees, from first principles, then through the code in priors/dirichlet.py and priors/base.py as it stands on main after the landing. Every number on this page was measured on the current code (setup with each figure).

The overview is the ideas and the decisions. The code tour adds the implementation, function by function. The deep dive adds the derivations.

§0

The family on one page

All four priors are one construction. Put the bins at the leaves of a tree. At every internal node, split the node's mass among its children with an independent Dirichlet. A bin's fraction is the product of the branch shares on its path from the root. That is a Dirichlet tree (Dennis 1991). The other three are particular trees:

PriorTreeConcentrationsWhat it adds over Dirichlet
Dirichlet(α)one node, K childrenαkthe baseline: one concentration per bin, all correlations negative
GeneralizedDirichlet(a, b)a chain ("caterpillar"): bin 1 vs the rest, bin 2 vs the rest, …Beta(ak, bk) per step2(K−1) parameters instead of K; correlations can be positive
DirichletTree(tree, α)any tree you giveone per branchbins in a group move together
PolyaTree(c, power, base)balanced binary tree over ordered 1-D binsc·mp·2G₀(child)/G₀(parent) at depth mmulti-scale smoothness that stays conjugate

Because each split is an independent Dirichlet, the whole tree stays conjugate: given latent bin counts, each split's posterior is Dirichlet(α + counts below each branch). That is why Gibbs, EM, mix-SQP (for the Dirichlet) and mean-field VB work in closed form for every member, and why method="auto" can route all of them to Gibbs.

Code tour

The code mirrors this: Dirichlet has its own bound class, and the other three are subclasses of _TreePrior that only build a _TreeStructure; one bound class, _BoundTree, does all the numerics for every tree. Both bound classes inherit the ILR coordinates from _SimplexBound, which inherits the engine interface from BoundPrior.

§1

The Dirichlet

Draw K independent Gamma(αk, 1) variables and divide by their sum: the result is Dirichlet(α). The density on the simplex is

$$p(\rho\mid\alpha)=\frac{\Gamma(A)}{\prod_k\Gamma(\alpha_k)}\prod_k \rho_k^{\alpha_k-1},\qquad A=\sum_k\alpha_k .$$

The mean is α/A, so the shape of α sets the expected population and its total A sets how tightly draws cluster around it (like A pseudo-objects). With αk < 1 the density goes to infinity at the faces where ρk = 0, and draws pile up near the corners: most bins nearly empty, a few holding the mass.

One property surprises people: every correlation is negative, and for symmetric α it is exactly −1/(K−1), whatever α is. Concentration changes how far draws spread, not how bins co-vary. With K = 8 we measured −0.14 for both α = 1 and α = 0.1 (40,000 draws each). That is why neighbouring bins in a smooth population need a different prior.

Explorer: Dirichlet draws on the 3-bin simplex

3,000 draws, made the way the package makes them (_dirichlet_draw: Gamma variates in log space, so α as small as 0.05 never gives exact zeros). The corners are the bins; a point near corner k has most of its mass in bin k. Slide α below 1 and the draws leave the middle for the edges and corners.

Code tour · Dirichlet, _BoundDirichlet

Construction. Dirichlet(alpha) takes a scalar, a length-K array or "reference" (α = 1/K, resolved when bound). Three named constructors cover the usual sources of α:

  • Dirichlet.reference(K): α = 1/K (Berger, Bernardo & Sun 2015).
  • Dirichlet.from_counts(counts, strength=1, base=1): α = base + strength·counts, a reference sample as pseudo-counts.
  • Dirichlet.from_base_measure(concentration, base): αk = concentration·Bk with B the bin masses of a base density (flat in the bins' measure by default). This is the one that stays consistent when bins are merged.

Binding resolves α against the bins and precomputes A and the normalising constant once:

class _BoundDirichlet(_SimplexBound):
    def __init__(self, prior, bins, alpha):
        super().__init__(prior, bins)
        self.alpha = alpha
        self.pseudocounts = alpha - 1.0            # what EM's M-step adds
        self.A = float(alpha.sum())
        self._const = gammaln(self.A) - gammaln(alpha).sum()

    def _lp_eta(self, rho, log_rho):               # density in softmax logits η
        lp = float(np.dot(self.alpha, log_rho)) + self._const
        return lp, self.alpha - self.A * rho       # and its gradient in η

Note _lp_eta uses α, not α − 1: it is the density of the logits η, which includes the Jacobian ∏ρk of the softmax (deep dive below). The conjugate methods are one line each: posterior_sample draws Dir(α + counts), map_from_counts returns (counts + α − 1)₊ normalised, vb_update returns α + counts.

Draws. _dirichlet_draw normalises Gamma variates in log space with softmax. For shapes below 1, _log_gamma_variates uses Gamma(a) = Gamma(a+1)·U1/a in logs; plain draws underflow to exactly 0 for about 12% of Gamma(0.003) variates, and an exact zero would make a bin's log-likelihood −∞.

Deep dive · the ILR coordinates and the Jacobian

Gradient-based engines (NUTS, L-BFGS, Laplace) need unconstrained coordinates. All simplex priors share one map, in _SimplexBound:

$$x\in\mathbb R^{K-1}\;\xrightarrow{\;V\;}\;\eta=Vx\in\mathbb R^K\;\xrightarrow{\text{softmax}}\;\rho,\qquad V=\text{Helmert basis},\;V^\top V=I,\;\mathbf 1^\top V=0 .$$

V spans the sum-zero subspace, so η is a centred log-ratio and the map is one-to-one. The density of x is the density of ρ times the Jacobian of x ↦ ρ, which is √K · ∏k ρk:

$$\log p(x)=\log p(\rho)+\sum_k\log\rho_k+\tfrac12\log K .$$

For the Dirichlet the ∑ log ρk cancels the −1 in the exponents, which is why _lp_eta has α·log ρ and the constant ½ log K lives in _log_jac_const. The gradient with respect to η is α − A·ρ (differentiate α·log softmax(η)); with respect to x it is Vᵀ(α − Aρ + ∂ℓ/∂η), the likelihood's gradient added before the one matrix product, in log_prior_and_grad.

In x the density is bounded for every α > 0: as ρk → 0, log p(x) ~ αk log ρk → −∞ at a rate set by αk. Small αk means a slowly decaying tail toward log ρk = −∞, which is the NUTS difficulty of §6, not a singularity.

§2

Dirichlet trees

A tree gives you correlation structure the Dirichlet cannot. Put bins 0–3 under one node and 4–7 under another: the root split decides how much mass goes left or right, and every bin on the side that gains mass gains together. With all branch concentrations 2 and K = 8, bins 0 and 1 (same side) correlate +0.10 and bins 0 and 7 (opposite sides) −0.33 (40,000 draws). A Dirichlet with the same mean can only give −0.14 everywhere.

The tree is still a distribution on the simplex with mean and variance you can read off: the mean of a bin is the product of the mean branch shares on its path. With equal concentrations per node the mean is uniform over each node's children, not over the bins: an unbalanced tree gives its shallow bins more prior mass.

Code tour · _TreeStructure

A user writes a tree as nested lists, [[0, 1], [2, [3, 4]]]. _parse_nested walks it in pre-order into a flat list of nodes (parents before children), each a list of ("leaf", k) or ("node", c) children, and refuses nodes with fewer than two children. _TreeStructure then flattens all branches into one array of slots, so every numerical operation is a matrix product instead of a recursion:

ArrayShapeMeaning
slot_alpha(S,)the concentration of every branch, node by node
ptr(C+1,)slots of node c are ptr[c]:ptr[c+1] (CSR-style)
slot_mem(S, K)which bins lie under each branch
node_mem(C, K)which bins lie under each internal node
A_node(C,)total concentration of each node's branches
leaf_coef, node_coef(K,), (C−1,)exponents of the density on the simplex (deep dive)
slot_nodes(S, C−1)which non-root nodes lie under each branch

With these, composing branch shares θ into bin fractions is one line, exp(log θ @ slot_mem) (with exact zeros carried through), and counting a bin histogram up the tree is slot_mem @ counts. Validation happens here too: leaves must be exactly 0..K−1 once each, every non-root node needs exactly one parent.

class _BoundTree(_SimplexBound):
    def sample(self, n, rng):                       # one Dirichlet per node, then compose
        theta = self.tree.draw_theta(self.tree.slot_alpha, rng, size=n)
        return np.maximum(self.tree.compose(theta), _TINY)

    def posterior_sample(self, counts, rng, exposure=None):
        t = self.tree                               # conjugacy: branch α + counts below it
        return np.maximum(t.compose(t.draw_theta(t.slot_alpha + t.slot_counts(counts), rng)), _TINY)
Deep dive · the tree's density on the simplex

Let θs be the share of branch s at its node c(s), so θ restricted to a node is Dirichlet(αs) and nodes are independent. Write ρc for the total fraction under node c (ρroot = 1). The branch share is θs = ρchild(s)/ρc(s). Changing variables from the θ's (∑(mc−1) = K−1 free coordinates) to ρ, node by node from the leaves up, the Jacobian of node c's split is ρc−(mc−1), and collecting powers gives

$$\log p(\rho)=\text{const}+\sum_{k}(\alpha_{\mathrm{pa}(k),k}-1)\log\rho_k+\sum_{c\ne\text{root}}\bigl(\alpha_{\mathrm{pa}(c),c}-A_c\bigr)\log\rho_c ,$$

which is the module docstring's formula, with leaf_coef = αpa(k),k − 1 and node_coef = αpa(c),c − Ac. It is linear in the logs of leaf and node masses, so log_density is two dot products and its gradient two matrix products. Setting every node to one level recovers the Dirichlet; the caterpillar with ak = αk, bk = ∑j>kαj makes every node coefficient zero, which is the classical proof that the generalised Dirichlet contains the Dirichlet.

The mode. In branch coordinates the log-density times the likelihood of counts n is ∑s xs log θs with xs = (n + leaf_coef summed under s) + (node_coef summed over nodes under s). Each node's θ is then maximised independently by θs ∝ max(xs, 0), which is exactly map_from_counts. When some xs is negative the maximum sits on the boundary, θs = 0: the density is unbounded there (§6).

§3

The generalised Dirichlet

Connor & Mosimann (1969) break a stick: V1 ~ Beta(a1, b1) takes a share for bin 1, V2 takes a share of the rest for bin 2, and so on. In tree terms it is a chain: each node splits off one bin and passes the remainder down. Two parameters per step instead of one per bin let the variance of each step be set separately from its mean, and correlations can become positive.

The default reproduces Dir(a): GeneralizedDirichlet(a) sets bk = (K − 1 − k)·a, and its log-density equals Dirichlet(a)'s to machine precision (checked on 5 random points, K = 8). Setting b yourself changes the mean. With a = b = 1 the mean halves at every step, (0.50, 0.25, 0.125, …, 0.008, 0.008) for K = 8, with correlations from −0.66 to +0.41 (40,000 draws). That is rarely what someone writing GeneralizedDirichlet(1, 1) expects; the question at the end asks whether the API should guard it.

Code tour · GeneralizedDirichlet._structure
for k in range(K - 1):
    right = ("leaf", order[K - 1]) if k == K - 2 else ("node", k + 1)
    nodes.append([("leaf", order[k]), right])     # bin k vs the rest
    alphas.append(np.array([a[k], b[k]]))

The stick is broken in bin order unless order permutes it. On a 2-D grid the bin order is the flattened row-major order, so "the rest" after a bin is not a geometric neighbourhood (§7).

§4

Pólya trees

A Pólya tree (Ferguson 1974; Lavine 1992) is a balanced binary Dirichlet tree on an ordered axis: split the range in two, split each half in two, and so on. Each split is a Beta whose concentration grows with depth m as c·mp. Coarse splits are free to vary; fine splits are held close to the base measure G₀. The result is a prior that is rough at large scales and smooth at small ones, and still conjugate. With power p = 2 the infinite tree gives absolutely continuous densities (Lavine 1992); with p = 0 every level is equally variable.

The binned version in binference: K bins split into index halves (the left half takes the extra bin when a range is odd), split concentrations c·mp·2G₀(child)/G₀(parent) so that the prior mean is G₀ at every level. The default c = 1, p = 2, flat G₀ on 8 bins gives Beta(1, 1) at the root, Beta(4, 4) at depth 2 and Beta(9, 9) at depth 3 (read from slot_alpha). Neighbouring bins then correlate +0.72 and bins at opposite ends −0.60 (40,000 draws), the multi-scale smoothness the Dirichlet lacks.

Code tour · PolyaTree._structure
def build(lo, hi, level):                 # bins lo..hi-1 under one node
    mid = (lo + hi + 1) // 2              # left half takes the extra bin
    for j, (clo, chi) in enumerate(((lo, mid), (mid, hi))):
        ...                                # a leaf, or recurse at level + 1
        a[j] = self.c * level**self.power * 2.0 * mass(clo, chi) / mass(lo, hi)

It refuses categorical and N-D bins, and base measures with a zero-mass bin. Overflow of level**power at extreme powers is caught by the final positivity check.

Code tour · how MAP picks a solver for these priors

MAP reads two of these answers. With pseudocounts ≥ 0 (Dirichlet with all α ≥ 1; with a selection, only α = 1) it runs mix-SQP. Otherwise, if unbounded_density() is False, SQUAREM-accelerated EM on the simplex; if True, L-BFGS in the ILR coordinates, where the density is bounded and the "mode on the simplex" (which may be a corner) is replaced by the mode in x. The default Pólya tree is in the last group (§6), so its best fit is the L-BFGS mode in x.

§6

Small concentrations and unbounded densities

A density on the simplex is unbounded when some exponent of the tree formula is negative. For the Dirichlet that means some αk < 1. For trees the test is subtler, because a node coefficient αpa(c),c − Ac is usually negative and the leaves under it compensate. _BoundTree.unbounded_density collects, for each branch, the leaf and node exponents below it; any negative total means the density blows up as that branch's share goes to zero.

Unbounded does not mean improper: the prior still integrates to one, and in the ILR coordinates every one of these densities is bounded. It has two practical effects:

  • Point estimates. The mode on the simplex can sit on a face, with some fractions exactly zero, so MAP uses L-BFGS in x for these priors (§5).
  • NUTS. Bins without data drift toward log ρ → −∞ along slowly decaying tails. At Dirichlet(0.1) with K = 20, 27.5% of prior components are below 10⁻⁶ and the median smallest component is 8 × 10⁻¹⁶ (20,000 draws). A sampler has to walk tens of units in log space to cover that.

Since the landing this matters less in practice: method="auto" sends every conjugate prior to Gibbs when the missing information is at most 0.98, and Gibbs draws small concentrations exactly. The open question from step 2.1, what NUTS should do with small concentrations, is still yours (below).

§7

How these priors read the bins

Each member sees a different part of the bins' geometry, and none sees all of it:

PriorUsesIgnores
Dirichlet(α), symmetricnothing: equal mean fraction per binwidths, order, neighbours; on unequal bins the implied density is ∝ 1/width
Dirichlet.from_base_measurebin masses of a base density in the measure coordinateorder and neighbours
GeneralizedDirichletan order (bin order, or order)widths; on N-D grids the row-major order is geometrically arbitrary
DirichletTreethe groups you giveeverything else
PolyaTreethe order, and the base measure for its meansplits by bin index, not by base-measure mass; 1-D only

A symmetric Dirichlet is not consistent under merging bins: merge two bins of Dir(1) and the merged bin is Beta(2, K−2), not the Dir(1) you would write for K − 1 bins. from_base_measure is consistent, because merging adds the α's. This and the default α (1 or 1/K) belong to step 3.5.

  • 1. Small concentrations under NUTS (parked since step 2.1). Options: leave it to method="auto", which sends conjugate priors to Gibbs; reparametrise (tree-matched coordinates, question 2); or add a tail-aware metric in NUTS.Default and recommendation: leave it to auto, and revisit with the benchmark matrix in step 4.2 if a NUTS-only case needs it.
