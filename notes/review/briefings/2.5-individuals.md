# Briefing 2.5: Population, this sample, each object (record)

Interactive page: `2.5-individuals.html`. Code: `results.py` `_IndividualMixin` (l. 112–315).

- realized_counts: per ρ draw, labels z_i ~ Cat(r_i(ρ)) (Mult for integer weights;
  weighted labels for non-integer) → exact joint draws; narrower than ρ (no shot
  noise). With selection counts detected objects only; full-sample version possible
  with absolute S (#46).
- assignment_probabilities: Rao-Blackwellised mean of r_ik over ≤500 evenly spaced
  draws; uses L̃ (detected-object posterior); not leave-one-out; PointEstimate gives
  plug-in r(ρ̂) (no ρ uncertainty). predict_proba / log_predictive for new objects.
- sample_values: Gaussian → per-axis truncated normals; loglike → 64-point inverse
  CDF (1-D, Python loop); else uniform in bin. All inherit flat-within-bin.
  Explorer (known narrow-peak population, d = 0.38, σ = 0.05): TV to truth,
  10 bins: histogram 0.276 (mean shift 0.018 ≈ σ/3), hat basis 0.076; 20 bins 0.123
  / 0.060; 40 bins 0.061 / 0.015; σ = 0.2 (2 bins), 10 bins: 0.235 / 0.066 (mean
  shift 0.003).
- Proposals: value draws from each input's within-bin info (density; samples
  resampled with 1/π weights; warn for tables/binned); B-spline value draws ∝ φ_k L;
  joint truncated draws for correlated Gaussians; plug-in vs full named distinctly
  (#35); leave-one-out per-object posteriors; full-sample realised counts under
  selection; vectorise the loglike path.
