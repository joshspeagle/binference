# Briefing 3.1: The Dirichlet family (record)

Interactive page: `3.1-dirichlet-family.html` (three levels: overview, code tour, deep dive;
explorers for Dirichlet draws on the 3-simplex, any tree on K = 8 with its correlation
matrix, and Pólya-tree draws on 16 bins). Files: `priors/dirichlet.py`, `priors/base.py`,
on `main` after the landing.

- One construction: a Dirichlet tree (independent Dirichlet split per node; a bin's
  fraction is the product of its branch shares). Dirichlet = one node; generalised
  Dirichlet = caterpillar; Pólya tree = balanced binary tree over ordered 1-D bins with
  split concentrations c·m^p·2G₀(child)/G₀(parent). Conjugate throughout: posterior
  split = Dir(α + counts below each branch).
- Code: `Dirichlet` → `_BoundDirichlet`; `DirichletTree`, `GeneralizedDirichlet`,
  `PolyaTree` build a `_TreeStructure` (flat slot arrays: slot_alpha, ptr, slot_mem,
  node_mem, A_node, leaf_coef, node_coef, slot_nodes) used by one `_BoundTree`. Both
  inherit ILR coordinates from `_SimplexBound`.
- Tree density on the simplex: const + Σ_k (α_pa(k),k − 1) log ρ_k
  + Σ_{c≠root} (α_pa(c),c − A_c) log ρ_c. Mode per node θ ∝ max(x, 0) (`map_from_counts`).
- Measured (K = 8, 40,000 draws per row; neighbour = bins 0,1; far = bins 0,7):

  | Prior | Unbounded | Neighbour | Far |
  |---|---|---|---|
  | Dirichlet(1) | no | −0.14 | −0.14 |
  | Dirichlet(0.1) | yes | −0.14 | −0.14 |
  | GeneralizedDirichlet(1) (= Dir(1)) | no | −0.14 | −0.14 |
  | GeneralizedDirichlet(1, 1) | yes | −0.66 | −0.23 |
  | DirichletTree two groups, α = 2 | yes | +0.10 | −0.33 |
  | PolyaTree() (c = 1, p = 2) | yes | +0.72 | −0.60 |
  | PolyaTree(power = 0) | yes | +0.13 | −0.24 |
  | PolyaTree(c = 10) | no | +0.82 | −0.71 |

  Symmetric Dirichlet correlations are −1/(K−1) whatever α is. GD(a) reproduces Dir(a)
  to machine precision; GD(1, 1) has means halving per bin. Dirichlet(0.1), K = 20:
  27.5% of components below 1e-6, median smallest component 8e-16 (20,000 draws).
- Open (QUESTIONS): small concentrations under NUTS (default: leave to auto); tree-matched
  coordinates (default: Helmert, test in 4.2); GD(a, b) changing the mean (default: as is,
  documented); Pólya splits by index and 1-D only (default: as is); one source of geometry
  (recommend an explicit `order` for GD on N-D grids).
