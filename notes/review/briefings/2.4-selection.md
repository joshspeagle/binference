# Briefing 2.4: Selection, in the code (record)

Interactive page: `2.4-selection.html`.

- `Selection`: per-bin values > 0 + mode ("observed"/"true"); `as_selection`
  enforces explicit mode (D9); zero values refused (unidentifiable bins);
  mutable (audit: add immutability guard).
- Model: true mode scales L columns by S once; normaliser −W log(S·ρ) both modes;
  rates −S·λ; gradient n̂ − WρS/(S·ρ); `_detect` = S/max S for imputation;
  model-level selection overrides the likelihoods' (1.3 item).
- Engines: NUTS/Laplace via log_prob only (correct); EM imputes Wρ(1−S)/(S·ρ)
  (correct, scale-free fixed point); mix-SQP solves φ = Sρ/(S·ρ) with rows L/S,
  flat prior only (correct); Gibbs NegBin(W, S·ρ) missed objects (exact; audit
  checked both modes); VB plug-in (not an ELBO ascent, G-6); log_predictive divides
  by S·ρ (correct); missing_information ignores selection (M-2).
- Scale: with the 1/N total prior, Σ_m (1/(W+m)) C(W+m,W)(1−p)^m p^W = 1/W, so
  p(ρ|D) ∝ p(ρ) Π(L̃ρ)/(S·ρ)^W is invariant to S → cS. Totals, imputed missed counts
  and #9 rates need absolute S; Selection doesn't record which (G-4 mocks clip S>1:
  ρ=(0.5,0.5) fitted as (0.33,0.67)).
- New finding: within-bin selection bias. S_k must be the population-weighted bin
  average; flat averaging repeats the flat-within-bin assumption. Explorer (10 bins on
  [0,1], population e^{−z/0.2}, logistic edge at 5.3 bins): edge 0.2 bins wide → bin 6
  off 11% (= 1 s.d. at N ≈ 6,600); 0.1 bins → 15% (N ≈ 3,500); 1 bin → 2.3%
  (N ≈ 120,000); population scale 1 → 2.2% (N ≈ 45,000). Fix: callable S(z) at
  internal resolution (#10, #4, #5), include in #6.
- Gaps vs decisions: #7 names, #8 combined, #10 inputs/from_injections, #30 joint
  (one more conjugate Beta block in Gibbs), #9 rates, #41 selected population φ;
  audit M-2, G-4, O-1, T-2; no on-measurement mock.
