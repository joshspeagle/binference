# Briefing 2.2: Bins, volumes and binning bias (record)

Interactive page: `2.2-bins.html` (https://claude.ai/artifact/DoPC2R94vpAETmZSpsRKei).

- `Bins`: immutable; 1-D (edges, linear, log, from_centers), N-D rectilinear
  grids (C-order cells, volumes = products of widths), categories (volume 1,
  no geometry). Left-closed bins, last bin closed. `coarsen` returns a
  fine→coarse map used by `rebin`.
- Volumes enter: mass↔density likelihood representation, interim priors,
  `density()` outputs, base measures (`from_base_measure`, PolyaTree),
  logistic default mean, mocks. A symmetric Dirichlet ignores them.
- `Bins.log` is log-spaced edges in the z coordinate: flat within bins means
  flat in z. Alternative bin shape: flat in log z. General fix: a measure on
  `Bins` that every component reads (parked).
- Binning bias computed exactly in the large-N limit: ρ∞ = argmax ∫p(d) log
  Σρ_k L_k(d); statistical variance from the Fisher information of the same
  integral; N_crit = min_k σ_k² / bias_k². Harness: `experiments/2.2_ncrit_harness.js`.
  Results (N_crit; flat-in-z → linear B-spline): exponential, K=10, σ=0.15:
  1.5e3 → 1.1e4; σ=0.05: 2.8e3 → 6.6e4; two peaks: 8.5e2 → 3.5e4; narrow
  peak K=15 σ=0.1: 4.9e2 → 3.0e3. Log bins, 1/z population: flat-in-z
  5.6e4, flat-in-log-z exact (6.7e9, quadrature-limited), splines 2.7e5.
- To discuss: Bins with a measure; B-splines as default bin shape; an N_crit
  planning tool; warning when likelihood mass falls outside the support;
  masked N-D grids.
