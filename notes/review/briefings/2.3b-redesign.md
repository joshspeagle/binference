# Briefing 2.3b: Redesigning the inputs (record)

Interactive page: `2.3b-redesign.html`. Responds to Josh's comments on 2.3.

- §1 Two priors: `PopulationPrior` (over ρ; today's `priors.*`) vs `InterimPrior`
  (one fixed density π(z), divided out). The object fixes: mass/density ambiguity
  (I-1), distribution objects, adaptive quadrature, pointwise π for samples,
  flat in which coordinate (z or measure u), and a required `kind`/`interim` so
  posteriors are never silently read as likelihoods. Possible shared `Density`
  class (base measures, measure density, injection distributions, simulate).
  Arguments ledger started: `notes/review/api-ledger.md`.
- §2 Samples (Josh: realisation of the PDF, no KDE): L_ik ≈ (Z_i/S) Σ_s φ_k(z_s)/π(z_s),
  pointwise π (today: per-bin Π_k, exact only if π flat within bins); works for
  hat bases. Unbiased for L_i·ρ but log is Jensen-biased: Δlog𝓛 ≈ −½ Σ_i V_i(ρ),
  ∝ N/S and larger far from the interim. Experiment `experiments/2.3_samples_mc.py`:
  N=1e3,S=100: −2.0±2.7 at truth; N=1e3,S=1e3: −0.24±0.52; N=1e4,S=100: −25±8;
  N=1e4,S=1e3: −2.5±2.5 (far from interim: −88 … −919). Need S ≳ N here.
  Proposed: Σ V_i diagnostic, n_eff under fitted population, opt-in Dirichlet floor.
- §3 One integral (∫ f_i φ_k/π), three integrators: exact CDF, adaptive
  quadrature/QMC, Monte Carlo. Merge function/distributions into one density
  constructor (name TBD); from_gaussian fast path; from_samples MC path.
- §4 Binned measurements: truth bins, measurement bins, response R_jk, counts.
  `Response` object (from simulation or labelled data, Dirichlet column
  uncertainty) + `from_binned` replacing `from_response`.
- §5 Classifiers: label shift ⇒ L_ic = p(s_i|c) valid for any score. Route A
  (posteriors ÷ π_train: needs calibration + effective π_train), B (confusion
  matrix), C (score bins); B/C need only label shift + validation set.
  Experiment `experiments/2.3_classifier_routes.py` (binary, θ=0.2, N=2000,
  Nval=500): CC +0.095 always; A best when calibrated (rms 0.013) but +0.046
  (T=0.5), −0.096 (T=2), −0.113 (wrong π_train); B/C unaffected (≈0, rms
  0.024–0.032); label-shift violation biases all (A +0.051, B +0.028, C +0.051);
  B/C give a free predictive check of the score distribution.
- §6 Explorer (JS, Gibbs for B/C, grid for A, χ² predictive check).
- §7 Response uncertainty, 68% coverage: plug-in 0.23–0.41; draw-averaging
  (log-mean-exp) fails with many bins (0.49/0.61 with 200/3000 draws at M=10,
  0.22/0.28 at Nval=100); cut 0.65–0.69; Gibbs over (labels, θ, R) 0.63–0.69,
  lowest rms. Implication for DECISIONS #10 (selection draws): treat selection
  as parameters; draw-averaging only with an effective-draw diagnostic.
