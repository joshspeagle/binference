- [ ] **How each prior uses the bin structure** (Josh, 2026-10-23). Facts from the code: Dirichlet ignores geometry and volumes (symmetric α = equal prior mean *fractions*, i.e. density ∝ 1/width on unequal bins; not consistent under merging bins); `from_base_measure` uses volumes but its default total concentration 1 gives per-bin α ≈ 1/K (small-concentration regime). Generalized Dirichlet uses only an ordering: bin order by default, which for N-D grids is the flattened row-major order (geometrically arbitrary). Dirichlet trees use only group membership. Pólya trees use the base measure (volumes by default) for the prior mean but split by bin *index* halves (dyadic in log z on log bins; unbalanced when K is not a power of 2), and reject N-D grids. Smoothness priors: the random walk works in bin-index steps (ignores widths), the GP in the linear bin coordinate (audit P-1): inconsistent with each other on unequal bins. Design question: should every prior take its geometry from one place (the bins' metric/measure, DECISIONS #4/#5), with N-D generalisations (k-d / quadtree Pólya trees; geometry-aware GD order)? (3.1 / 3.2 / Phase 7)
