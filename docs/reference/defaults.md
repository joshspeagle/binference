# Defaults

This page lists the default of every public parameter, and the run-time defaults and
thresholds that the code sets inside functions. Every engine and sampler also takes
`rng=None` and `progress=False`. `rng=None` draws fresh entropy from the operating
system, so pass a seed for reproducible draws.

The tables are written by `docs/_scripts/defaults_table.py` from the code itself.
Values come from the signatures and the named constants, and each parameter's
description is the first sentence of its entry in the docstring. A threshold written
inside a function names that function, and the script checks the line of code that sets
it. The documentation job of CI, and the test suite where numpydoc is installed, fail
when the page and the code disagree. The guides explain the choices:
{doc}`../guides/engines`, {doc}`../guides/results` and {doc}`../guides/validation`.
