# Concepts

These pages explain the ideas behind binference in words and pictures, before any
formula is needed. Each page answers one question and asks you to run no code. The
{doc}`tutorials <../tutorials/index>` and {doc}`guides <../guides/index>` show the code,
and {doc}`How it works <../how-it-works/index>` gives the mathematics.

Read the pages in this order. Each builds on the one before it.

1. {doc}`bins-and-likelihoods`: what binference needs to know about each object.
2. {doc}`likelihoods-and-posteriors`: why a posterior must lose its interim prior first.
3. {doc}`population-and-objects`: the population, the objects you observed, and each
   object's posterior.
4. {doc}`priors-on-the-simplex`: what a prior on the fractions says, and when it matters.
5. {doc}`selection`: how a catalogue with missing objects is corrected.
6. {doc}`engines`: what each engine computes, and when it is exact.

The {doc}`glossary <../reference/glossary>` defines every term, and the
{doc}`notation page <../reference/notation>` every symbol.
